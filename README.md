# Soccer Tournament
This repository contains a project for managing a soccer tournament using a SQL database and a Java console application. The application was built by me and a teammate as part of a programming course. The SQL database stores information about teams, players, matches, and results. The Java application provides a simple user interface for managing the tournament, such as adding teams and players, scheduling matches, and updating results. The application uses JDBC to interact with the database. This project allowed us to develop our skills in SQL database design and management, as well as in data analysis and visualization.
